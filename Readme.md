# BubblesOnChunkGen

A plugin/addon that keeps the soul-sand bubble columns generated by Terra's CHIMERA preset from growing the rivers they sit in. CHIMERA places soul sand (with a bedrock block directly below it) at the bottom of rivers; soul sand under water produces an upward bubble column that pushes water to the surface. Left alone, that surface water spreads sideways into the banks, creating new source blocks and causing rivers to expand — both visually wrong and a source of cascading-water lag. This plugin freezes that flow.

## How it works

World generation does all the block placement now — the plugin only maintains the columns at runtime. On **every** chunk load (whether freshly generated or loaded from disk) it does the same idempotent work:

1. Blanket-freezes water flow in the chunk while it settles.
2. After a short delay (5 ticks), scans the chunk for the **bedrock signature**. For each bedrock block found in the river-Y range, the soul sand is expected directly above it.
3. **Restores griefed soul sand**: if the block above a bedrock signature is no longer soul sand (a player broke it), it is silently replaced, so the column keeps working.
4. **Freezes the water column**: walking up from the soul sand, every water-source / bubble-column block that is adjacent to air is registered for flow prevention, until air above the column is reached.
5. **Caps the surface**: the first air/flowing-water block above the column is replaced with a thin (level-7) water block and frozen, giving a gentle visual step instead of an abrupt full-block-to-air transition.

Because every step is idempotent, there is no "new chunk vs. existing chunk" distinction — the same path runs on all platforms regardless of whether the platform exposes an `isNewChunk` flag.

### Water flow prevention

The plugin tracks the frozen coordinates in a `HashSet` (O(1) lookups) and cancels any water-flow event whose source **or** destination is a frozen coordinate. This is invisible to players (unlike barrier blocks) and is removed when chunks unload. The flow event differs per platform:

- **Bukkit/Paper** — `BlockFromToEvent`
- **Fabric / NeoForge** — a Mixin on `FlowingFluid#spreadTo` (the addon JAR is also a Fabric/NeoForge mod so the mixin is registered)
- **Allay (Bedrock)** — `LiquidFlowEvent`
- **Minestom** — informational only; Minestom does not run vanilla fluid physics by default

### Worldgen contract

The plugin keys entirely off the **bedrock-below-soul-sand** signature, so the generator (Terra/CHIMERA) must place, at each bubble-column spot:

- `minecraft:soul_sand` at the river bottom, with water above it, and
- `minecraft:bedrock` directly below the soul sand.

Bedrock naturally occurs only far below the river-Y scan range (`MIN_Y`–`MAX_Y`), so the signature is unambiguous.

## Dedication chest

The dedication chest is an easter egg placed by **world generation**, not by this plugin:

- A low-probability `.tesf` structure (with `dedication` in its id) places a `minecraft:chest` beside a column and calls `loot(x, y, z, "bubbles-chunk-gen:dedication")`.
- Terra creates a loot-table registry but its core addons never populate it, so the Terra addon registers the `bubbles-chunk-gen:dedication` table (emeralds + diamonds) into every pack as it loads. Those items are placed through Terra's cross-platform item handle, so they appear on **all** platforms.
- Terra loot tables cannot encode a written book's title/author/pages, so the addon also listens for Terra's `LootPopulateEvent` (fired by that `loot(...)` call) and injects the "CHIMERA — Dedicated to Finnian and Armin" written book. The book works on **Bukkit/Paper, Fabric, and NeoForge**; on Minestom/Allay the chest and its loot items still appear, but not the book.

This keeps all chest placement in worldgen and removes the per-platform chest code the plugin used to carry.

## Commands

- `/bubblesdebug` — Toggles debug logging on/off (op-only). When enabled, logs per chunk: how many water blocks were frozen, how many soul sand blocks were restored, and each surface-step coordinate.

## Requirements

Two distribution paths:

**As a Terra addon** (recommended — works on every platform Terra supports)
- Terra with a configuration (e.g. CHIMERA) that places soul sand + a bedrock signature for bubble columns
- One of:
  - Paper 1.21+
  - Fabric (MC 26.1+) — the addon JAR is also a Fabric mod so its water-flow mixin is registered
  - NeoForge (MC 26.1+) — same, also a NeoForge mod
  - Minestom (2026.05+) — fluid physics not run by default, so flow blocking is informational
  - Allay (Bedrock) — *experimental*; bubble column physics and `liquid_depth` semantics differ from Java

The Terra-addon JAR is a single artifact, safe to install on Fabric/NeoForge servers without Terra (the mixin no-ops when no FlowBlocker is registered).

**As a standalone Bukkit plugin** (no Terra)
- Paper 1.21+
- Some other source of soul sand + bedrock signatures under water
